# mtf-calculator
MTF Financial Model Calculator helps traders evaluate leveraged stock positions by calculating net profit/loss, ROE, interest costs, brokerage, taxes, break-even returns, and leverage impact. Analyze different holding periods, return scenarios, and MTF interest rates to make more informed margin trading decisions.

# MTF Calculator

Static GitHub Pages-ready site generated from the attached `MTF_Model.jsx`.

## Publish on GitHub Pages

1. Create a new GitHub repository named `mtf-calculator`.
2. Upload `index.html` from this folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your default branch and `/ (root)` folder.
6. Save. Your site will be published at:

`https://YOUR_GITHUB_USERNAME.github.io/mtf-calculator/`

## Notes

- This version is converted from JSX into a standalone static HTML page.
- It does not require React, Node.js, Vite, or a build step.
- Charts are loaded through the Chart.js CDN.
